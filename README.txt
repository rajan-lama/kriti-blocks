Kriti Blocks is a Gutenberg-focused WordPress plugin that adds reusable blocks for creating modern, responsive layouts directly in the editor.

== Description ==

Kriti Blocks gives WordPress users a set of custom blocks for building polished content sections without writing custom code. It includes layout-focused blocks such as Section, Columns, Column, Buttons, Carousel, Advance Header, and Icon.

The plugin is designed to be lightweight, modular, and easy to extend while staying compatible with the modern WordPress block editor experience.

== Features ==

* Custom Gutenberg blocks for page layout and content presentation
* Responsive styling and layout controls
* Clean, editor-friendly interface
* Lightweight architecture for better performance
* Built with WordPress block editor APIs and React

== Installation ==

1. Upload the `kriti-blocks` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Open the block editor and search for Kriti Blocks blocks.

== Frequently Asked Questions ==

= Does Kriti Blocks work with my theme? =

Yes. Kriti Blocks is designed to work with most modern WordPress themes that support the block editor.

= Can I use the blocks in the editor without coding? =

Yes. The blocks are ready to use from the Gutenberg editor once the plugin is activated.

= Is the plugin developer-friendly? =

Yes. The plugin uses a modular structure and is built with WordPress block development conventions.

* Fixed: Author archive titles in the Archive Header block showed HTML tags
* Fixed: A saved column gap on the Text and Pricing Table blocks could be lost when the page was reopened
